# Simple Icons

Brand marks for the stack and the project tool icons of the « Bascule » world
pages, as used on the approved mockup (2026-11-14).

- Source: Simple Icons 13.21.0, `https://cdn.jsdelivr.net/npm/simple-icons@13.21.0/icons/<name>.svg`
- License: CC0 1.0. Brand marks remain trademarks of their owners.
- Single-path, 24×24, no script. Rendered monochrome in the world's ink.

File names are Simple Icons' slugs, not the registry slugs (`dotnet`,
`reactivex` for RxJS, `amazonwebservices` for AWS, `nodedotjs` for Node.js,
`adobephotoshop` for Photoshop, `nextdotjs` for Next.js). React Native uses `react`.

Not in Simple Icons 13.21.0, shown by name only: Azure, Azure DevOps (both
removed from the set), Segment, TestFlight, CI/CD and unit tests (practices, not brands). Google Play Console
uses the `googleplay` mark.
